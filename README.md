# Chalhoub Store API

Static JSON API for the Chalhoub Store Expo app (React Native assessment).
Served by GitHub Pages at **https://raw.githubusercontent.com/fwinmaclinux/chalhoub-store-api/main/v1**.

| Endpoint | Content |
| -------- | ------- |
| `/v1/categories.json` | Category tabs |
| `/v1/products.json` | Featured product id + product summaries (lists, search) |
| `/v1/products/<id>.json` | Full product: image URLs, title, price, sizes, colours, description, related products |
| `/v1/images/<file>.png` | Product images |

Generated by `scripts/build-api.mjs` in the app repository. Do not edit by hand: change `data/catalog.json` there and run `npm run publish:api`.
